## 二、老师提问的两类形式与应对总则

### 形式 A：「这块代码在哪？」——定位三步法

1. **先定页面**：看到界面元素 → 按菜单名找 `frontend/src/views/` 下同名文件（8 个业务页 + Layout 框架 + Login/Register）；
2. **再定区域**：文字/结构 → 在 `<template>` 里搜界面上的中文文案（如「记一笔」「导出 CSV」）；颜色/字号 → 看该文件 `<style scoped>` 块；
3. **最后定归属**：若是全站统一效果（按钮主色、卡片圆角、金额颜色、图表色）→ 在 `style.css` 的 `:root` 变量或 `utils/charts.js` 里。

答不上时的话术：「这块样式我确认一下具体行数」→ 打开文件用 Ctrl+F 搜文案，10 秒内定位。

### 形式 B：「把这个颜色/字号/间距改一下」——修改四步演示套路

**定位 → 改 → 热更新看效果 → 改回去**。Vite 开发服务器 HMR 秒级生效，整个过程 30 秒内完成，是最出彩的环节。改完后记得说「我改回去」，避免脏工作区。

## 五、高频知识点问答

### 框架与工程
1. **前端技术栈？** Vue 3.5（组合式 API + `<script setup>`）＋ Element Plus（UI）＋ ECharts 6（图表）＋ Pinia（状态）＋ Vue Router（路由）＋ Axios（请求）＋ Vite 8（构建）。
2. **为什么前后端分离？** 前端只负责展示与交互，通过 REST API 调后端；可独立开发部署，前端构建产物是纯静态资源。
3. **Vite 代理干什么？** `vite.config.js` 把 `/api` 转发到 `localhost:8080`，开发期避免跨域，生产由 Nginx 做同样的事。
4. **路由懒加载？** 每个页面用 `() => import('../views/xxx.vue')` 动态导入，按需加载，首屏更快。

### 路由与状态
5. **登录守卫怎么实现？** `router/index.js` 的 `router.beforeEach`：无 token 访问业务页 → 重定向 `/login` 并带 `redirect`；已登录访问登录/注册 → 回 `/dashboard`；未知路径兜底回首页。
6. **token 存哪里？** localStorage（跨标签页保持登录）+ Pinia（内存态）。退出时先清 localStorage 再重置内存，避免身份残留。
7. **Pinia 里存了什么？** token、user、family、members；`isAdmin` 控制管理员按钮显隐；`memberMap` 把成员 id 映射成姓名。
8. **401 怎么处理？** `utils/request.js` 响应拦截器统一解包 `{code,message,data}`；401 时清凭证并跳登录页，其余错误统一 `ElMessage` 提示。

### Vue 核心
9. **ref 和 reactive 区别？** ref 包装任意类型（模板自动解包），reactive 只包装对象；项目里表单/列表多用 ref。
10. **computed 和 watch 区别？** computed 是派生值（有缓存，如结余、执行率）；watch 是副作用（如 ChartBox 监听 option 变化重绘图表，deep:true）。
11. **v-model 本质？** `:value` + `@input` 语法糖；表单组件全用它做双向绑定。
12. **v-if 和 v-show 区别？** v-if 条件渲染（销毁重建），v-show 只是 display 切换；管理员按钮用 v-if，弹窗用组件自身的 visible。
13. **父子组件通信？** 父传子 props（StatCard 收 title/value/chips），子传父 emit；本项目多为接口驱动，较少跨组件事件。
14. **scoped 样式原理？** 编译后给元素加 data-v-xxx 属性选择器隔离；要改 Element 组件内部用 `:deep()`（如登录页 `:deep(.el-input__wrapper)`）。
15. **生命周期用了哪些？** `onMounted` 拉数据/初始化图表；`onBeforeUnmount` 移除 resize 监听、`chart.dispose()` 防内存泄漏。

### 图表与数据
16. **ECharts 怎么封装？** `ChartBox.vue` 统一容器：init → `setOption(notMerge:true)` → window resize 自适应 → 卸载 dispose；页面只管构建 option 传入。
17. **为什么图表颜色固定顺序？** 分类色跟随实体（如房产永远是蓝），切换月份/筛选时不重排；色板经过色盲友好校验（ΔE≥8）。
18. **金额显示怎么处理？** 后端返回 BigDecimal 数值，前端 `format.js` 千分位格式化；金额输入用正则限两位小数，避免浮点精度问题。
19. **CSV 导出怎么做？** 调接口拿文本流 → `new Blob` → 临时 URL → 模拟 `<a>` 点击下载；BOM 头让 Excel 正确识别 UTF-8 中文。
20. **前端做了哪些安全处理？** 图表 tooltip 用 `escHtml()` 转义用户可控文本（分类名/商家名），防存储型 XSS（`charts.js` L127-133）；请求统一带 token；管理员操作按钮前端 `isAdmin` 控制（后端再校验）。
21. **仪表盘数据怎么加载？** `Promise.all` 并发请求 5 个接口（汇总/趋势/占比/最近流水/预警），失败互不影响。
