# 使用手册

《管家婆─家庭收支管理系统》在本机（WSL2）从零启动、测试与关闭的完整操作说明。

## 一、运行环境

| 组件 | 说明 |
|------|------|
| 数据库 | 本机用户级 MySQL 8.0.44，端口 **3307**，数据目录 `~/apps/mysql-data` |
| 后端 | Spring Boot 4 + Java 17，端口 **8080** |
| 前端 | Vue 3 + Vite 开发服务器，端口 **5173**（/api 自动代理到 8080） |
| 数据库口令 | root / root（仅本机；配置在 gitignored 的 `backend/src/main/resources/application-local.properties`，不进入仓库） |

以下所有命令均在**项目根目录** `~/mywork/ruanjiankaifashujian/325-` 下执行。

## 二、启动流程（从零开始）

### 第 1 步：启动数据库

```bash
/home/b210/apps/mysql/start-mysql.sh
```

已启动时会自动跳过。

### 第 2 步：初始化数据库

```bash
mysql -h 127.0.0.1 -P 3307 -uroot -proot < sql/init.sql
```

该脚本会重建 `family_finance` 库，可反复执行（会清空数据）。

### 第 3 步：启动后端（终端 1）

```bash
cd backend && ./mvnw spring-boot:run
```

就绪标志：`curl http://localhost:8080/api/auth/me` 返回 HTTP 200（响应体 code=401 表示未登录，属正常，说明服务已启动）。

### 第 4 步：启动前端（终端 2）

```bash
cd frontend
npm install    # 仅首次需要
npm run dev
```

浏览器打开 http://localhost:5173

## 四、运行集成测试

测试脚本要求全新数据库，请在浏览器注册账号**之前**执行（或重跑第 2 步后执行）：

```bash
mysql -h 127.0.0.1 -P 3307 -uroot -proot < sql/init.sql
python3 docs/integration_test.py
```

预期 **53/53 PASS**（54 条用例中的 SEC-05 为前端 HTTP 级验证，建议答辩前用浏览器走一遍）。执行记录见 [集成测试用例.md](集成测试用例.md) 第 4 节。

## 五、关闭全部进程

方式一（推荐）：在启动后端、前端的终端里分别按 `Ctrl+C`。

方式二（命令行）：

```bash
pkill -f FamilyFinanceApplication      # 关闭后端
pkill -f spring-boot:run               # 关闭后端 Maven 包装进程（如有残留）
pkill -f vite                          # 关闭前端
mysqladmin -h 127.0.0.1 -P 3307 -uroot -proot shutdown   # 优雅关闭 MySQL
```

确认端口已全部释放（无输出即已关闭）：

```bash
ss -ltn | grep -E ':(8080|5173|3307)'
```

## 六、常见问题

| 现象 | 处理 |
|------|------|
| `./mvnw: Permission denied` | `chmod +x backend/mvnw`（git 索引中执行位丢失所致） |
| 报 `sql/init.sql: No such file or directory` | 请回到项目根目录再执行（不要在 backend/ 目录下） |
| 8080 端口被占用 | 先执行第五节关闭旧进程，再重新启动 |
| 修改了后端代码没生效 | 重启后端（Ctrl+C 后重新 `./mvnw spring-boot:run`） |
| 换一台机器运行 | 需自行安装 MySQL 8 / Java 17 / Node.js，并按 README「本地运行」创建 `application-local.properties` 填入本机口令 |
