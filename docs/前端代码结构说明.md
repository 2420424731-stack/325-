# 前端代码结构说明（管家婆·家庭收支管理系统）

> 技术栈：Vue 3.5（组合式 API + `<script setup>`）+ Vite 8 + Element Plus 2.14 + Pinia + Vue Router + ECharts 6
> 目录：`frontend/`

## 一、目录总览

```
frontend/
├── index.html              # HTML 入口壳（挂载点 #app）
├── package.json            # 依赖清单与脚本（npm run dev / build）
├── vite.config.js          # Vite 配置：/api 代理 → http://localhost:8080
├── public/                 # 静态资源（vite.svg 等）
└── src/
    ├── main.js             # 应用入口：装配 Pinia / 路由 / Element Plus
    ├── App.vue             # 根组件（仅放 <router-view>）
    ├── style.css           # 全局样式 + 墨绿主题色覆盖 + 卡片统一样式
    ├── router/index.js     # 路由表 + 登录守卫
    ├── stores/user.js      # Pinia 全局状态（登录态 / 家庭 / 成员）
    ├── utils/              # 通用工具
    │   ├── request.js      #   Axios 封装（统一解包 / 401 处理）
    │   ├── format.js       #   金额 / 日期 / 百分比格式化
    │   └── charts.js       #   ECharts 样式常量 + tooltip XSS 转义
    ├── api/                # 后端接口封装（每个后端模块一个文件，共 10 个）
    ├── components/         # 复用组件
    │   ├── ChartBox.vue    #   ECharts 统一容器
    │   └── StatCard.vue    #   指标卡片
    └── views/              # 页面组件（10 个：8 业务页 + 登录 + 注册）
```

## 二、入口与全局（4 个文件）

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架，只有一个 `<div id="app">` 挂载点 |
| `src/main.js` | 应用启动：创建 Vue 实例 → 依次安装 Pinia、路由、Element Plus（中文语言包）→ **先加载 Element 官方样式、再加载 `style.css`**（顺序保证主题色覆盖生效）→ 挂载 |
| `src/App.vue` | 根组件，只含 `<router-view>`，所有页面在此渲染 |
| `src/style.css` | 全局样式中心：`body` 浅绿底；`:root` 中用 CSS 变量将 Element Plus 主色调为墨绿 `#1b623c`；统一 `.el-card` 圆角与阴影；收入 / 支出 / 提示等通用色类 |

## 三、路由与全局状态（2 个文件）

### `src/router/index.js` — 路由表 + 登录守卫
- `/login`、`/register` 为独立页面；
- 其余 8 个业务页全部挂在 `Layout.vue`（框架页）下作为子路由，`meta.title` 供顶栏显示页面名；
- 守卫逻辑：
  - 无 token 访问任何业务页 → 重定向 `/login`（并携带 `redirect` 参数）；
  - 已登录访问 `/login`、`/register` → 重定向 `/dashboard`；
  - 未知路径 → 兜底重定向 `/dashboard`。

### `src/stores/user.js` — Pinia 全局状态
- `state`：`token`、`user`（当前用户，含角色）、`family`（当前家庭）、`members`（成员列表）；token 与 user 持久化到 localStorage；
- `getters`：`isAdmin`（是否 ADMIN）、`memberMap` / `memberOptions`（成员 id↔姓名，供列表与下拉使用）；
- `actions`：`login` / `register`（成功后自动登录）、`fetchContext`（拉取 `/auth/me` 补齐家庭与成员）、`logout`（先清 localStorage 再重置内存态，避免身份残留）。

## 四、工具层 utils（3 个文件）

### `src/utils/request.js` — Axios 统一封装
- 实例 baseURL = `/api`，请求自动携带 `Authorization`（token）；
- 响应统一解包：`{code, message, data}` 中 code=200 直接返回 `data`；
- **401 自动清除本地与内存凭证并跳转登录页**（避免登录态残留）；
- 其余错误统一 `ElMessage.error` 提示。

### `src/utils/format.js` — 格式化函数集
`money`（千分位金额）、`date / datetime`（日期）、`pct / signedPct`（百分比）、`currentMonth`（当前 yyyy-MM）、`monthStart / monthEnd`（月初/月末日期）。

### `src/utils/charts.js` — ECharts 统一样式
- 常量：`SERIES_COLORS` 分类固定色板、`TYPE_COLORS`（收入蓝/支出橙）、`INK` 墨色分层；
- 模板函数：`baseTooltip` / `itemTooltip` / `baseAxis` / `lineSeries` / `moneyAxisLabel`；
- `escHtml()`：HTML 转义工具，用于图表 tooltip 中包裹分类名、商家名等**用户可控文本**，防存储型 XSS。

## 五、接口层 api（10 个文件，一一对应后端模块）

| 文件 | 封装的后端接口 |
|---|---|
| `auth.js` | 登录 / 注册 / `/auth/me`（用户+家庭+成员上下文）/ 退出 / 修改密码 |
| `transaction.js` | 流水分页查询 / 详情 / 增删改 / **CSV 导出** |
| `category.js` | 分类树（type=1 收入 / 2 支出）、分类增删改 |
| `stats.js` | 统计全家桶：月度汇总、近 N 月趋势、分类 / 成员 / 商家 / 片区 / 标签汇总 |
| `analysis.js` | 智能分析：环比同比、异常预警（规则 R1~R7）、月度分析报告 |
| `budget.js` | 月度预算列表 / 执行率 / 增删改 |
| `asset.js` | 资产列表 / 汇总（总资产、贷款、净资产、类型分布）/ 增删改 |
| `loan.js` | 贷款增删改查 + 还款计划测算（等额本息 / 等额本金逐月明细） |
| `member.js` | 家庭成员增删改查 |
| `family.js` | 家庭信息读取 / 修改名称描述（管理员） |

## 六、复用组件 components（2 个文件）

| 文件 | 作用 |
|---|---|
| `ChartBox.vue` | **ECharts 统一容器**：初始化实例、option 变化自动重绘（notMerge）、loading 态、空数据占位、窗口 resize 自适应、卸载时 dispose 防泄漏 |
| `StatCard.vue` | **指标卡片**：标题 + 大号金额 + 可选环比/同比角标；`accent`（income/expense/balance）切换渐变顶条配色 |

## 七、页面层 views（10 个文件）

### 认证页（2 个）
| 文件 | 功能 |
|---|---|
| `Login.vue` | 登录页：整页绿色渐变背景 + 毛玻璃「温馨家庭插画 + 标语」 + 白色圆角卡片（金币 logo、带图标输入框、墨绿渐变大按钮） |
| `Register.vue` | 注册页：与登录同风格；注册即自动创建「家庭 + 户主成员 + 内置收支分类」，成功后自动登录进入系统 |

### 主框架（1 个）
| 文件 | 功能 |
|---|---|
| `Layout.vue` | **应用框架**：左侧墨绿渐变侧栏（金币品牌 logo + 8 个菜单项高亮/悬停态 + 底部当前家庭卡）；顶栏（页面标题 + **提醒铃铛**（聚合本月预警与贷款还款日提醒）+ 家庭名 pill + 用户下拉退出）。全部业务页嵌于其 `<router-view>` |

### 业务页（8 个，对应侧栏菜单）
| 文件 | 菜单 | 功能 |
|---|---|---|
| `Dashboard.vue` | 首页仪表盘 | 时段问候欢迎条；本月收入 / 支出 / 结余三张指标卡；近 6 月收支趋势折线；本月支出分类占比环形图；最近 10 笔流水；本月预警摘要（前 3 条，可跳分析页） |
| `Transactions.vue` | 收支管理 | 流水列表：日期范围 / 类型 / 分类树 / 成员 / 关键词筛选 + 分页 + 导出 CSV；「记一笔」弹窗（树形分类选择器、标签多选可自建、成员可不选=家庭整体）；支持接收分析页钻取参数（categoryId / keyword） |
| `Categories.vue` | 分类管理 | 收入/支出 Tab 切换的树形表格；管理员增删改（内置分类禁删、有子分类/有流水禁删可停用、最多三级） |
| `Members.vue` | 成员管理 | 成员表格增删改；关系可选 户主/配偶/子女/父母/其他；户主与有流水记录的成员由后端禁删 |
| `Analysis.vue` | 统计分析 | 环比/同比指标卡（收入/支出/结余）；近 12 月趋势；支出分类 Top 8 柱状；商家 Top 10；片区分布 Top 8；预警与关注项列表（R1~R7 等级色标、可点击钻取流水）；一键重新生成月度文字分析报告 |
| `Assets.vue` | 资产管理 | 资产 + 贷款两大板块：净资产汇总卡、资产类型分布图、资产列表增删改；贷款列表、月供信息、逐期还款计划可视化 |
| `Budgets.vue` | 预算管理 | 按月（yyyy-MM）查看预算列表与执行率进度条（超额标红）；管理员增删改预算；家庭总预算（不选分类）或分类预算 |
| `Profile.vue` | 个人中心 | 账号信息展示、修改密码（校验原密码）；管理员可编辑家庭名称与描述 |

## 八、一次请求的完整数据流

```
页面组件 views/*.vue
      │  调用
      ▼
api/*.js 接口函数 ──► utils/request.js（axios 实例）
                             │ 自动附加 Authorization 头 / 统一解包
                             ▼
                     Vite 开发代理 /api
                             ▼
                     Spring Boot 后端 :8080
                             ▼
                     MySQL 数据库 :3306
```

## 九、目录职责速查（记忆口诀）

- `main.js` 装配，`router` 导航，`stores` 状态；
- `utils/request` 发请求，`format` 格式化，`charts` 管图表；
- `api/` 十个文件 = 后端十个模块的"翻译官"；
- `components/` 两张脸：装图表的盒（ChartBox）、装指标卡（StatCard）；
- `views/` 十页面：八个菜单页 + 登录注册页，全包在 `Layout` 框架里。
