# 集成测试用例

| 项目 | 内容 |
|------|------|
| 文档版本 | v1.0 |
| 编写日期 | 2026-09-06 |
| 被测系统 | 管家婆─家庭收支管理系统（Spring Boot 后端 + Vue 3 前端） |
| 测试级别 | 集成测试（前后端联调 + 接口级） |

## 1. 测试环境与前置条件

1. 执行 `sql/init.sql` 初始化 MySQL 8 数据库（共 8 张表：user / family / family_member / category / transaction / budget / asset / loan）；
2. 配置后端 `backend/src/main/resources/application-local.properties` 本机数据库账号口令；
3. 启动后端：`cd backend && ./mvnw spring-boot:run`（默认 8080 端口）；
4. 启动前端：`cd frontend && npm install && npm run dev`（默认 5173 端口，Vite 代理转发 `/api`）；
5. 准备浏览器（Edge/Chrome）与一个接口调试工具（Apifox/Postman 或 `curl`）。

**约定**：

- 登录令牌放入请求头 `Authorization: <token>`；
- 无特殊说明的用例，均需先执行 **AUTH-01 注册** 得到令牌；
- 用例按顺序执行时存在数据依赖，可用示例账号：`demo` / `demo123456`，家庭名 `演示家庭`。

## 3. 详细用例

### 3.1 认证与用户

| 编号 | 标题 | 前置 | 步骤 | 预期 |
|------|------|------|------|------|
| AUTH-01 | 注册（自动建家/户主/内置分类） | 数据库已初始化 | `POST /api/auth/register`，body：`{"username":"demo","password":"demo123456","nickname":"演示员","familyName":"演示家庭"}` | 返回 code=200，data.token 非空，data.user.role=ADMIN；数据库 user/family/family_member/category 各新增 1/N 条（内置分类约 26 条） |
| AUTH-02 | 重复用户名注册被拒绝 | AUTH-01 已执行 | 再次调用 AUTH-01 请求体 | code=400，message 含"用户名已存在" |
| AUTH-03 | 登录成功 | AUTH-01 | `POST /api/auth/login`，body：`{"username":"demo","password":"demo123456"}` | code=200，返回 token |
| AUTH-04 | 密码错误登录失败 | AUTH-01 | 登录 body 密码改为 `wrong` | code=400，message="用户名或密码错误" |
| AUTH-05 | 当前用户上下文 | AUTH-01 | `GET /api/auth/me` 带令牌 | code=200，data 含 user/family/members；members[0].relation=户主 |
| AUTH-06 | 退出登录 | AUTH-03 | `POST /api/auth/logout` 带令牌 | code=200；再用旧令牌访问 `/api/auth/me` 返回 code=401 |
| AUTH-07 | 修改密码 | AUTH-03 | `PUT /api/auth/password`，body：`{"oldPassword":"demo123456","newPassword":"demo1234567"}` | code=200；用新密码登录成功，旧密码登录失败 |
| AUTH-08 | 原密码错误 | AUTH-03 | 修改密码 body 的 oldPassword 填错 | code=400，message="原密码错误" |
| AUTH-09 | 新密码过短 | AUTH-03 | 修改密码 newPassword 填 `123` | code=400（参数校验失败） |

### 3.9 安全与健壮性

| 编号 | 标题 | 前置 | 步骤 | 预期 |
|------|------|------|------|------|
| SEC-01 | 未登录拦截 | 无 | 不带令牌访问任意业务接口（如 `GET /api/transactions`） | code=401 |
| SEC-02 | 非管理员权限 | 注册第二个普通账号（当前系统注册即 ADMIN，可临时改库或按后续家庭加入功能验证） | 普通成员执行 POST/PUT/DELETE 管理接口 | code=403 |
| SEC-03 | 参数校验 | AUTH-01 | 必填字段缺省 / 超长 / 越界值 | code=400，message 为中文提示 |
| SEC-04 | 跨家庭数据隔离 | 注册家庭 A、家庭 B 两个账号 | 用 A 的令牌访问 B 的数据 id（如流水、资产、分类） | code=400/404，返回"不存在"，不泄露 B 的数据 |
| SEC-05 | 前端全链路 | 前后端均已启动 | 浏览器走通：注册→登录→录收支→看仪表盘/统计/分析→资产管理→预算→个人中心改密→退出 | 各页面无报错，数据一致 |

### 4.1 测试发现并修复的缺陷

| # | 缺陷 | 影响用例 | 修复 |
|---|------|----------|------|
| 1 | 重复注册返回 code=500（`BizException` 默认码），文档预期 400 | AUTH-02 | 显式指定 400 |
| 2 | 越权/不存在类错误（流水/资产/贷款/预算/分类/成员）返回 500，文档预期 400/404 | SEC-04 | 统一改为 404 |
| 3 | 删除内置且含子分类的顶级分类时先命中"内置不可删"，文档预期"先删除子分类" | CAT-06 | 调整校验顺序：子分类 → 内置 → 流水 |
| 4 | PUT 局部更新被 DTO 必填校验拦截（只传 amount/value 返回 400） | TRANS-06、ASSET-04 | TransactionDTO/AssetDTO 引入校验分组（Create 必填 / Update 仅约束已传字段） |

```bash
BASE=http://localhost:8080/api

# 月度分析报告
curl "$BASE/analysis/report?month=2026-09" -H "Authorization: $TOKEN"
# 修改密码

  -d '{"oldPassword":"demo123456","newPassword":"demo1234567"}'
```
