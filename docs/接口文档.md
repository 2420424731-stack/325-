# 《管家婆─家庭收支管理系统》接口文档

| 项目 | 内容 |
|------|------|
| 文档版本 | v1.0 |
| 更新日期 | 2026-09-05 |
| 适用后端 | family-finance（Spring Boot 4.1.1，端口 8080） |
| 接口前缀 | `/api`（开发期前端经 Vite 代理转发） |
| 数据格式 | JSON（UTF-8），时间 `yyyy-MM-dd` / `yyyy-MM-dd HH:mm:ss`，金额为数字（后端 DECIMAL 两位小数） |

## 1. 通用约定

### 1.1 统一返回格式

所有接口返回结构一致（设计文档 6.3）：

```json
{ "code": 200, "message": "success", "data": { } }
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数校验失败 / 业务规则拒绝（message 为可直接展示的中文提示） |
| 401 | 未登录或登录已过期 |
| 403 | 无权限（如非管理员执行管理操作、账号禁用） |
| 500 | 系统异常 |

### 1.2 鉴权

- 登录/注册成功后返回 Sa-Token 令牌（UUID 格式，有效期 24 小时），前端存入 localStorage；
- 除 `POST /api/auth/register`、`POST /api/auth/login` 外，**所有接口要求登录**，令牌放在请求头：
  `Authorization: <token>`
- 未登录访问返回 `{code: 401}`（HTTP 状态仍为 200，前端按 code 处理）。

### 1.3 数据隔离与权限

- **家庭数据隔离**：所有查询由服务端强制附加 `family_id` 条件，无法越权访问其他家庭数据；
- **管理员（户主，role=ADMIN）**：可管理成员、分类、资产、贷款、预算，可改删家庭内任何流水；
- **普通成员（role=MEMBER）**：可记账，仅能修改/删除自己创建的流水（`created_by` 校验，越权视为"记录不存在"）；
- **逻辑删除**：流水删除为逻辑删除（`deleted=1`），MyBatis-Plus 自动过滤。

### 1.4 分页

分页接口返回：`{ "records": [], "total": 128, "current": 1, "size": 10 }`

## 2. 认证与用户 `/api/auth`

### POST /api/auth/register — 注册

注册即创建账号 + 家庭 + 户主成员 + 内置收支分类（事务保证原子性），成功后**自动登录**。

**请求体**：

```json
{
  "username": "zhangsan",        // 必填，3-20 位，唯一
  "password": "123456",          // 必填，6-32 位，BCrypt 加密存储
  "nickname": "张三",            // 选填，≤50 字符，默认同用户名
  "familyName": "张三家"          // 必填，≤50 字符
}
```

**响应** `data`（LoginVO）：

```json
{
  "token": "64f749e6-bbbb-4ef6-a17b-3ec3b83da0f1",
  "user": { "id": 1, "username": "zhangsan", "nickname": "张三", "avatar": null, "role": "ADMIN" }
}
```

**错误**：400 用户名已存在 / 参数校验失败（message 说明具体字段）。

### POST /api/auth/login — 登录

**请求体**：`{ "username": "zhangsan", "password": "123456" }`

**响应**：同注册（LoginVO）。**错误**：400 用户名或密码错误；403 账号已被禁用。

### GET /api/auth/me — 当前用户上下文

**响应** `data`（UserContextVO）：用户 + 家庭 + 成员列表（含停用外全部启用成员，供全站下拉）：

```json
{
  "user": { "id": 1, "username": "zhangsan", "nickname": "张三", "avatar": null, "role": "ADMIN" },
  "family": { "id": 1, "name": "张三家", "description": null, "createdBy": 1,
              "createdAt": "2026-09-05T10:00:00", "updatedAt": "2026-09-05T10:00:00" },
  "members": [
    { "id": 1, "familyId": 1, "userId": 1, "name": "张三", "relation": "户主",
      "birthday": null, "sortOrder": 0, "status": 1,
      "createdAt": "2026-09-05T10:00:00", "updatedAt": "2026-09-05T10:00:00" }
  ]
}
```

### POST /api/auth/logout — 退出登录（无请求体，返回 data=null）

## 5. 收支分类 `/api/categories`

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | /api/categories/tree?type=2 | 登录 | 分类树（type 必填：1 收入 / 2 支出） |
| POST | /api/categories | 管理员 | 新增分类 |
| PUT | /api/categories/{id} | 管理员 | 修改分类 |
| DELETE | /api/categories/{id} | 管理员 | 删除分类 |

**GET /tree 响应** `data`（List\<CategoryNodeVO\>，含停用分类，前端置灰）：

```json
[
  { "id": 6, "parentId": 0, "type": 2, "name": "餐饮支出", "icon": "🍚",
    "sortOrder": 0, "isSystem": 1, "status": 1,
    "children": [
      { "id": 8, "parentId": 6, "type": 2, "name": "外卖", "icon": null,
        "sortOrder": 1, "isSystem": 0, "status": 1, "children": [] }
    ] }
]
```

**POST/PUT 请求体**：

```json
{ "type": 2, "name": "宠物支出", "parentId": 0, "icon": "🐱", "sortOrder": 9, "status": 1 }
```

- `parentId` 为 0 或空 = 顶级分类；父分类必须同 type 且启用
- **修改约束**：type 不可变更；v1 不支持移动节点（parentId 不生效，删除重建）
- **删除约束**：系统内置分类（isSystem=1）、有子分类、已有流水挂载的分类均禁止删除（400 提示，可停用代替）
- 内置分类由注册时自动生成：收入 5 个一级；支出一级 8 个（餐饮/购物/交通/住房/医疗教育/人情往来/休闲娱乐/其他支出，前 6 个含二级子类）

## 6. 收支记录 `/api/transactions`

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | /api/transactions | 登录 | 分页 + 多条件查询 |
| GET | /api/transactions/{id} | 登录 | 详情 |
| POST | /api/transactions | 登录 | 记账 |
| PUT | /api/transactions/{id} | 本人或管理员 | 修改（局部更新） |
| DELETE | /api/transactions/{id} | 本人或管理员 | 删除（逻辑删除） |

### 查询参数（全部可选，GET）

| 参数 | 类型 | 说明 |
|------|------|------|
| page / size | long | 页码默认 1；每页默认 10，最大 100 |
| type | int | 1 收入 / 2 支出 |
| categoryId | long | 分类 id（选父分类自动含其所有子孙分类） |
| memberId | long | 经手成员 |
| merchant / region | string | 商家 / 片区（模糊匹配） |
| keyword | string | 关键词：模糊匹配 商家/备注/标签 |
| startDate / endDate | string | 业务日期范围，`yyyy-MM-dd` |

**响应** `data`（PageResult\<TransactionVO\>）：

```json
{
  "records": [
    { "id": 1, "type": 2, "categoryId": 8, "categoryName": "外卖",
      "amount": 35.00, "bizDate": "2026-09-08", "memberId": 1, "memberName": "张三",
      "merchant": "美团外卖", "region": "朝阳区望京", "tags": "外卖",
      "paymentMethod": "微信", "image": null, "note": null,
      "createdByName": "张三", "createdAt": "2026-09-08T12:00:00", "updatedAt": "2026-09-08T12:00:00" }
  ],
  "total": 74, "current": 1, "size": 10
}
```

### POST/PUT 请求体

```json
{
  "type": 2,                // 必填 1/2
  "categoryId": 8,          // 必填，须为叶子分类、与 type 一致、启用
  "amount": 35.00,          // 必填，>0，最多 2 位小数
  "bizDate": "2026-09-08",  // 必填 yyyy-MM-dd
  "memberId": 1,            // 选填，空=家庭整体
  "merchant": "美团外卖",   // 选填 ≤100
  "region": "朝阳区望京",   // 选填 ≤50
  "tags": "外卖",           // 选填 ≤100，逗号分隔（中英文逗号均可）
  "paymentMethod": "微信",  // 选填 ≤20：支付宝/微信/银行卡/现金/其他
  "image": null,            // 选填 ≤255 凭证图片地址
  "note": null              // 选填 ≤255
}
```

> **PUT 为局部更新**：请求体为 null 的字段不覆盖原值。

## 7. 统计 `/api/stats`（客观汇总）

### GET /api/stats/overview — 月度/年度收支汇总

参数：`year`（选填，空=当前年份，范围 2000~2100）、`month`（选填，1~12，空=整年）。

```json
{ "year": 2026, "month": 9, "income": 18300.00, "expense": 5117.00,
  "balance": 13183.00, "incomeCount": 2, "expenseCount": 11 }
```

### GET /api/stats/trend — 近 N 个月收支趋势

参数：`months`（默认 12）。返回 `data`：List\<TrendPointVO\>（**无数据月份补 0**，保证折线连续）：

```json
[ { "month": "2026-04", "income": 18300.00, "expense": 1332.00 }, ... ]
```

### GET /api/stats/category — 分类汇总

参数：`year`、`month`（选填）、`type`（必填 1/2）。

```json
[ { "categoryId": 9, "categoryName": "外出就餐", "type": 2, "total": 2250.00, "count": 2 } ]
```

### GET /api/stats/member — 按成员汇总

参数：`year`、`month`、`type`（选填，空=收支合计）。返回 List\<NameStatVO\>。

### GET /api/stats/merchant — 商家 Top N

参数：`year`、`month`、`type`（默认 2）、`categoryId`（选填）、`topN`（默认 10）。

```json
[ { "name": "全聚德", "total": 1800.00, "count": 1 } ]
```

### GET /api/stats/region — 片区分布

参数：`year`、`month`、`type`（默认 2）、`categoryId`（选填）。返回 List\<NameStatVO\>。

### GET /api/stats/tags — 标签汇总

参数：`year`、`month`、`type`、`tag`（选填；指定 tag 返回单标签汇总，否则返回各标签 Top 10）。返回 List\<NameStatVO\>。

## 8. 分析 `/api/analysis`（发现问题并解释）

参数 `month` 格式 `yyyy-MM`，空 = 当月。规则与设计文档 8.2 一一对应（阈值在 `AnalysisServiceImpl` 常量区，答辩可现场改规则重生成）。

### GET /api/analysis/compare — 环比/同比

```json
{
  "month": "2026-09",
  "income":  { "current": 18300.00, "mom": 18800.00, "yoy": null, "momPct": -2.7, "yoyPct": null },
  "expense": { "current": 5117.00,  "mom": 3812.00,  "yoy": null, "momPct": 34.2, "yoyPct": null },
  "balance": { "current": 13183.00, "mom": 14988.00, "yoy": null, "momPct": -12.0, "yoyPct": null },
  "conclusion": "支出较上月增长 34.2%，较去年同月无比较基准；收入较上月下降 2.7%。"
}
```

> `momPct/yoyPct` 为正=增长、负=下降；基准为 0 时返回 null（无意义比率）。

### GET /api/analysis/anomalies — 异常与关注项（R1~R7）

返回 `data`：List\<AnomalyVO\>：

```json
{
  "ruleCode": "R1", "title": "本月支出超出历史月均", "level": "danger",
  "dimension": "总支出", "current": 5117.00, "baseline": 999.18, "exceedPct": 412.1,
  "description": "本月支出 5,117.00 元，高于近 11 个月月均 999.18 元的 130% 预警线，超出 412.1%。",
  "suggestion": "建议查看本月支出明细（尤其单笔大额），对照下月预算进行压缩。",
  "drillCategoryId": null, "drillTag": null
}
```

| 规则 | 标题 | 级别 | 触发条件 |
|------|------|------|----------|
| R1 | 本月支出超出历史月均 | danger | 本月支出 > 前 11 个自然月月均 × 130%（有效月 ≥ 6） |
| R2 | 分类支出异常增长 | warning | 某分类本月 > 该分类历史月均 × 150% 且绝对差 > 200 元（有记录月 ≥ 3） |
| R3 | 预算超支 | danger | 实际支出 > 该月预算（家庭总预算或分类预算，无预算自动跳过） |
| R4 | 支出连续三个月增长 | warning | 本月、上月、上上月支出连续环比上升 |
| R5 | 收入来源集中 | info | 单分类收入占本月收入 > 80% |
| R6 | 外部餐饮消费分析 | info | 餐饮子树本月支出 + Top 商家 + 集中片区（参考卡片） |
| R7 | 人情往来支出 | info | 「礼尚往来」标签当年总额/笔数/占全年支出比 |

> `level`：danger 严重 / warning 提示 / info 参考卡片；`drillCategoryId`/`drillTag` 非空时前端可钻取到流水列表（`/transactions?categoryId=` 或 `?keyword=`）。

### GET /api/analysis/report — 月度分析报告

```json
{ "month": "2026-09", "text": "📊 2026 年 9 月分析报告\n\n一、本月概况\n  收入 18,300.00 元，…" }
```

`text` 为纯文本报告（\n 分行）：概况 → 发现的问题 → 参考信息 → 建议，前端 `pre-wrap` 直接展示。

## 10. 贷款管理 `/api/loans`（拓展 F10）

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | /api/loans | 登录 | 贷款列表 |
| POST | /api/loans | 管理员 | 新增贷款（月供自动测算） |
| PUT | /api/loans/{id} | 管理员 | 修改贷款（月供重新测算） |
| DELETE | /api/loans/{id} | 管理员 | 删除贷款 |
| GET | /api/loans/{id}/plan | 登录 | 还款计划测算 |

### POST/PUT 请求体

```json
{ "name": "望京房贷", "principal": 1000000.00, "annualRate": 0.038, "termMonths": 360,
  "startDate": "2021-01-01", "repaymentType": "equal_installment",
  "remainingPrincipal": null, "lender": "建设银行" }
```

- `annualRate` 为小数（3.8% = 0.038），范围 0~1；`termMonths` 1~600
- `repaymentType`：`equal_installment` 等额本息（默认）/ `equal_principal` 等额本金
- `monthlyPayment` 由后端测算：等额本息取固定月供，等额本金取首月月供
- `remainingPrincipal` 选填，默认 = 本金（已还部分贷款时手工填写）

**月供公式**（设计文档 9.2）：月利率 r = 年利率/12；等额本息 `M = P·r·(1+r)ⁿ / ((1+r)ⁿ−1)`；等额本金每期还 `P/n` 本金 + 剩余本金 × r 利息。

### GET /api/loans/{id}/plan 响应

```json
{
  "loanId": 1, "repaymentType": "equal_installment", "termMonths": 360,
  "monthlyPayment": 4659.57, "totalInterest": 677447.64, "totalPayment": 1677447.64,
  "items": [
    { "period": 1, "payment": 4659.57, "principal": 1492.90,
      "interest": 3166.67, "remainingPrincipal": 998507.10 },
    ...
    { "period": 360, "payment": 4662.01, "principal": 4647.29,
      "interest": 14.72, "remainingPrincipal": 0.00 }
  ]
}
```

> 明细按 10 位小数精度计算、展示四舍五入 2 位，**末期结清**避免尾差。

## 11. 预算管理 `/api/budgets`（拓展 F11）

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | /api/budgets?month= | 登录 | 某月预算列表（month 必填 yyyy-MM） |
| GET | /api/budgets/execution?month= | 登录 | 某月预算执行率 |
| POST | /api/budgets | 管理员 | 新增预算 |
| PUT | /api/budgets/{id} | 管理员 | 修改预算 |
| DELETE | /api/budgets/{id} | 管理员 | 删除预算 |

### POST/PUT 请求体

```json
{ "categoryId": 6, "budgetMonth": "2026-09", "amount": 2000.00 }
```

- `categoryId` 空 = **家庭总预算**；非空须为当前家庭的启用支出分类
- **唯一约束**：同一家庭同一月份同一分类（含总预算）仅一条，重复返回 400 "该分类该月预算已存在，请直接修改"

## 13. 附录：curl 快速体验

```bash
BASE=http://localhost:8080/api
# 注册（自动建家+内置分类）
curl -X POST $BASE/auth/register -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"demo123456","familyName":"演示家庭"}'
# 登录拿 token
TOKEN=$(curl -X POST $BASE/auth/login -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"demo123456"}' | jq -r .data.token)
# 记一笔支出
curl -X POST $BASE/transactions -H "Authorization: $TOKEN" -H "Content-Type: application/json" \
  -d '{"type":2,"categoryId":8,"amount":35.00,"bizDate":"2026-09-08","merchant":"美团外卖"}'
# 月度分析报告
curl "$BASE/analysis/report?month=2026-09" -H "Authorization: $TOKEN"
```
