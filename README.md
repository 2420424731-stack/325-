# 管家婆─家庭收支管理系统

《软件开发实践2》课程实践项目——基于 WEB 应用程序开发技术的家庭收支管理系统。

## 项目简介

面向"家庭"这一记账主体，提供家庭收入/支出的**录入、编辑、查询、统计、分析**全流程管理，并拓展家庭资产管理（房产、投资、股票、房/车贷款）能力，帮助家庭了解收支状况、发现消费问题、优化财务决策。

## 功能特性

- **收支管理**：以家庭成员为粒度（或家庭整体）录入收入/支出，支持商家、片区、标签（如"礼尚往来"）、支付方式等多维信息
- **分类管理**：多级树形分类，内置常用分类，支持自定义扩展
- **统计**：月度/年度收支汇总、分类占比、成员对比、月度趋势
- **分析**：环比/同比、异常支出预警（超月均 30%）、商家 Top N、片区分布、预算执行率、月度分析报告
- **资产管理（拓展）**：房产、股票/基金持仓、存款等资产登记与总资产统计；房贷/车贷管理与还款计划测算
- **预算管理（拓展）**：按分类设置月度预算并跟踪执行率

## 技术栈

| 端 | 技术 |
|----|------|
| 后端 | Java 17 + Spring Boot 3 + MyBatis-Plus + MySQL 8 + Sa-Token |
| 前端 | Vue 3 + Vite + Element Plus + ECharts + Pinia + Axios |
| 工具 | Maven、knife4j（接口文档）、Git |
